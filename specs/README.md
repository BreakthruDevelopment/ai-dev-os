# Specs

One spec per app, `NN-slug.md`, written by the planner from `templates/spec.md` at the start of its day.

When several apps are planned as a batch, the shared prep (template issues, cross-app order, Michael's steps and the
harness schedule) goes in `day-0-apps-N-M.md`, e.g. [`day-0-apps-5-8.md`](day-0-apps-5-8.md).
